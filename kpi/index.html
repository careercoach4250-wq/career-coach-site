Awareness (reach on Instagram and TikTok) is read from each platform's Insights every day, but it isn't a KPI: it doesn't decide anything that site visits by source can't. Our KPIs start at interest.

On track means: for a rate (a % or a per-user number), the latest value is at or above the target. For a count (visits, sign-ups, active users), the latest value is at or above a straight-line path from zero on Oct 26, 2026 to the target on the target date.

Counts only. This page never shows a person's name or email. KPI numbers come from kpi-data.json (the course format, read by the course website) and the funnel from funnel.json; each card names its query, and each day's value comes from that day's file in ceo/analytics/data/.
